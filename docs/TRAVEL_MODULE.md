# 旅游模块

与健康、日记平级的「旅游」tab，仅按需读取 `data/travel-visits/*.json`。
每条记录是 schema v1 `travel_visit`，复用公共 `owner_id`、版本、时间戳、
`deleted_at` 和 GitHub blob SHA 冲突检查。业务字段：

```json
{
  "travel_visit_version": 2,
  "province_id": "330000",
  "city": "杭州",
  "start_date": "2026-10-06",
  "end_date": "2026-10-08",
  "notes": "西湖、灵隐寺\n提前预约"
}
```

省份由用户明确选择，不根据城市名推断。开始/结束日期是必填自然日字符串，不转换成 UTC；允许同日，结束不得早于开始。
备注可选、最多 2,000 个字符，按纯文本展示并保留内部换行；空白备注作为空串保存。
旧 `travel_visit_version: 1` 的 `visited_on` 在读取时兼容为 `start_date = end_date`，
备注默认为空，公共元数据和删除状态保持不变。读取不写回旧文件，后续单条编辑、
删除或恢复保存为业务版本 2；不进行批量迁移。
新增、编辑、删除、恢复只写该条旅游文件；删除是软删除，回收站可恢复。
至少一条未删除记录才点亮该省，同省多次到访只计一个省。
刷新或其他设备重新连接后读取同一私有仓库；没有业务 localStorage 或离线保存。
保存和刷新互斥，表单阻止重复提交。取消不会调用保存。
读失败/数据无效时阻止写入，SHA 冲突保留当前表单并要求刷新核对。
刷新后重新点击记录的「编辑」可使用新的文件 SHA。

这是增量注册，没有迁移/重置旧文件，也不需要额外仓库权限。
现有导出/恢复包含旅游记录及回收站；缺少旅游字段的旧导出包仍可校验。
没有修改健康/日记业务或数据，也没有写入真实用户仓库。

地图资源、原始文件、Apache-2.0 许可、NOTICE 和可重复生成说明位于
[travel-map](../apps/github-pwa/app/workspace/travel-map/README.md)。
34 个区域均提供地图键盘按钮和省份列表按钮。港澳等小区域可直接从列表选择。
